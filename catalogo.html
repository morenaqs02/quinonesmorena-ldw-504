Catálogo

En Terra contamos con diferentes piezas de cerámica realizadas de manera artesanal.

Cada pieza puede tener diferentes formas, tamaños, colores y diseños. Nuestro catálogo está pensado para ofrecer objetos útiles y decorativos para todos los espacios de tu ambiente.

Tazas

Tazas de cerámica realizadas a mano, ideales para utilizar todos los días. Contamos con diferentes formas y diseños personalizados.

Platos

Platos de diferentes formas y diseños que pueden ser personalizados a gusto del cliente.

Macetas

Macetas de cerámica de diferentes tamaños para colocar plantas y decorar como más te guste.

Jarrones y floreros

Jarrones y floreros de diferentes tamaños, formas y colores para tus flores favoritas.

Tazones

Tazones de cerámica que pueden utilizarse para diferentes alimentos o como elementos decorativos.

Porta sahumerios

Porta sahumerios de cerámica con diferentes diseños, excelentes para decorar y darle un toque artesanal a los espacios.

Portavelas

Portavelas de cerámica, disponibles en diferentes formas y diseños para decorar distintos ambientes y que elijas tu favorito.

Piezas decorativas

También contamos con piezas decorativas diferentes, pensadas para darle un estilo artesanal y personal a cada espacio de tu casa.
